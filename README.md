# گزارش پیج‌های اینستاگرام

اپلیکیشن Nuxt 4 برای ثبت و پیگیری پیج‌های اینستاگرام: فالوور، بیو، آخرین پست و تاریخچه‌ی تغییرات (اسنپ‌شات) با خروجی اکسل.

## راه‌اندازی

```bash
npm install
npm run dev
```

سپس `http://localhost:3000` را باز کنید.

## حل مشکل فیلترینگ / خطای پروکسی ⚡

چون اینستاگرام در ایران فیلتر است، برنامه برای دسترسی به پروکسی نیاز دارد. این نسخه سه لایه‌ی پشتیبان دارد:

### ۱. تشخیص خودکار
اگر v2rayN یا Clash روی همین سیستم اجرا باشد، برنامه پورت‌های رایج را خودش امتحان می‌کند و اولین پروکسی سالم را ذخیره می‌کند. هیچ تنظیمی لازم نیست.

### ۲. تنظیم از داخل برنامه (پیشنهادی)
در صفحه **مدیریت پیج‌ها** روی **⚙️ تنظیمات پروکسی** کلیک کنید:
- روی «تست» هر گزینه کلیک کنید تا پینگ و سلامت آن را ببینید
- یا آدرس دستی وارد کنید (مثلاً `socks5://127.0.0.1:10808`)
- گزینه‌ی سالم را «ذخیره» کنید

### ۳. متغیر محیطی
در فایل `.env`:
```
INSTAGRAM_PROXY=socks5://127.0.0.1:10808
```

### اگر IP محدود شده باشد (401/403/429)
این یعنی سرور فعلی v2rayN توسط اینستاگرام بلاک شده — در خود v2rayN یک کانفیگ/سرور دیگر انتخاب کنید، بعد در تنظیمات برنامه دوباره تست بگیرید.

برنامه به‌طور خودکار بین چند روش استخراج جابه‌جا می‌شود (به‌ترتیب):

1. **صفحه‌ی HTML پروفایل با UA خزنده** — اطلاعات کامل پروفایل (فالوور، بیو، نام، تصویر)
2. **API وب اینستاگرام** (`web_profile_info`)
3. **endpoint عمومی** (`?__a=1`)
4. **صفحه‌ی embed پروفایل** (`instagram.com/<user>/embed/`) — مقاوم به محدودیت IP و منبع «تاریخ آخرین پست»
5. **سایت‌های mirror** (آخرین راه)

هر روش برای هر کاندید پروکسی («ذخیره‌شده → مستقیم») امتحان می‌شود و اگر روش اول تاریخ آخرین پست را نداشته باشد، از صفحه‌ی embed کامل می‌شود.

## امکانات

- افزودن پیج با لینک کامل یا @username (بررسی قبل از ثبت)
- **دریافت کلی**: دریافت اطلاعات همه‌ی پیج‌های لیست با یک کلیک (ترتیبی، با فاصله برای کاهش rate-limit) و نمایش خلاصه‌ی موفق/ناموفق
- **اسنپ‌شات کلی**: ثبت اسنپ‌شات از کل لیست در همان لحظه
- تاریخ آخرین پست ارسالی هر پیج (روز + فاصله‌ی زمانی مثل «۳ روز پیش»)
- گزارش pivot: اسنپ‌شات‌ها به‌صورت تاریخ × پاسخ فالوور در بازه‌ی زمانی (با تاریخ شمسی)
- **روند رشد** هر پیج در گزارش اسنپ‌شات: تغییر مطلق و درصدی نسبت به اولین اسنپ‌شات بازه
- خروجی اکسل راست‌به‌چپ: شیت «گزارش پیوت» (تاریخ‌ها به‌صورت ستون + روند رشد، آماده برای نمودار) و شیت «داده خام»
- خروجی اکسل گزارش پیج‌ها
- ذخیره‌سازی SQLite در `data/instagram.db`

> برای هر پیج در هر روز فقط یک اسنپ‌شات نگه داشته می‌شود؛ اگر همان روز دوباره اسنپ‌شات بگیرید، مقدار قبلی بروزرسانی می‌شود. تاریخ اسنپ‌شات بر اساس وقت تهران (UTC+3:30) محاسبه می‌شود.

## ساختار API

| مسیر | توضیح |
|---|---|
| `GET/POST /api/settings/proxy` | وضعیت / تست / ذخیره‌ی پروکسی |
| `GET /api/accounts` | لیست پیج‌ها |
| `POST /api/accounts` | افزودن پیج (با استخراج خودکار اطلاعات) |
| `DELETE /api/accounts/:id` | حذف پیج |
| `GET /api/instagram/fetch?id=` | بروزرسانی یک پیج |
| `POST /api/instagram/refresh-all` | بروزرسانی همه‌ی پیج‌ها |
| `GET /api/snapshots` | اسنپ‌شات‌ها (با فیلتر تاریخ) |
| `POST /api/snapshots` | ثبت اسنپ‌شات دستی (برای هر روز بروزرسانی می‌شود) |
| `POST /api/snapshots/capture-all` | اسنپ‌شات گروهی؛ `{"account_ids":[1,2]}` برای چند پیج مشخص، بدون بدنه برای همه |
| `GET /api/export/report` | خروجی اکسل گزارش |
| `GET /api/export/snapshots` | خروجی اکسل اسنپ‌شات‌ها |
